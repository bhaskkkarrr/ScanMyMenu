# ScanMyMenu 🍽️

A QR-based digital menu system for restaurants. Restaurant owners can manage their menu digitally, and customers can scan a QR code to instantly browse the menu — no app download required.

## 🚀 Features

### 👨‍💼 Restaurant Admin Panel
- Add, edit, and delete food items
- Manage food categories
- Auto-generated QR code for the restaurant's menu

### 👥 Customer Menu View
- Scan QR code to instantly view the menu
- Search food items by name
- Filter by food category
- Sort items by price or name
- Clean, mobile-friendly UI
